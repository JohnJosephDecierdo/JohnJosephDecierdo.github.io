01 / Browser-based video tools

Caption Deck↗

Open live app ↗ (opens in a new tab)View source ↗ (opens in a new tab)

A caption workflow, from video to export.
Transcribe, translate, style, and export captions in the browser.

Try the sample: play the timeline, switch languages, and change the caption style.

What it brings together

Whisper-based browser transcription, translation, caption styling, and SRT/VTT subtitle handling.

How it is built

HTML, JavaScript, Transformers.js, and browser APIs. Video processing, a service worker, and a web app manifest, deployed through GitHub Pages.
